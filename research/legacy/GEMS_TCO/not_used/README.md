# Archived GEMS_TCO modules

These seven modules were moved unchanged from `src/GEMS_TCO/not used/` on
2026-09-21.  They are historical research sources and are intentionally not
part of the installed `GEMS_TCO` package.

Some old notebooks refer to four of these modules through former top-level
package paths. Those imports were already stale before this move. The local
pre-refactor tag is only a private rollback snapshot and must not be included
in the clean public release because its history contains credentials.
