# Legacy setup and deployment notes

This directory preserves machine-specific environment, Amarel, and AWS notes
from earlier experiments. They reference retired source paths, extension names,
experiment scripts, and dependency combinations. They are retained only for
provenance and are not maintained, tested, installed, or included in release
distributions.

Use the root `README.md` and `pyproject.toml` for the supported installation
workflow. Do not run these historical deployment scripts without independently
reviewing and updating every path, dependency, and cloud-resource setting.
